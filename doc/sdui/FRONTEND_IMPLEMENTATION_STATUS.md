# SDUI 前端实施进度

依据后端仓库 `docs/sdui/frontend/IMPLEMENTATION_PLAN.md` 实施。本文只记录前端代码与验证证据，不代表真机验收。

## 已落地

- 终端遥测历史、趋势和连接日志响应按后端 DTO 校验设备身份、请求分页参数及字段类型；趋势桶允许后端合法返回的空时间戳/空聚合值，UI 只绘制有效数值点。
- 连接历史的当前会话和统计投影按后端 nullable DTO 建模；时间线在投影缺失时仍展示事件并明确标注当前会话/统计不可用，避免空对象访问造成整区渲染失败。
- 设备运行列表和运行详情共用一套后端投影解析器；核对 run/device 身份、状态枚举、非负且唯一的步骤索引、失败停止步骤和终态时间，并允许后端实体版本缺失时投影出的版本 0。
- 运行记录解析按后端运行时保留合法边界：平台在步骤前失败可无停止步骤摘要；跨设备目标缺失时摘要 target 可空。列表展示错误摘要，详情标注“步骤执行前失败”或“未发送到设备”。
- 调试事件 SSE 和请求 SSE 校验后端事件名、设备身份与各事件 payload 字段；无效或跨设备数据不进入事件表，也不会把流标为已连接。有效事件恢复后清除当前流错误提示。
- 阶段 F 旧路径全量扫描覆盖 `src/` 后，未发现节点工作流、独立 UI 模板、旧命令/事件目录或 Section Patch 路径及术语引用。
- 业务编辑器动作目录按后端 `{deviceId,schemaSynced,count,actions}` 投影校验身份、条数、重复项和文档字段；参考设备能力未同步时明确提示当前只含平台动作。设备交互目录同时核对设备身份、在线标记和唯一交互 ID。
- 业务编辑器字段表单覆盖目录声明的 `int`/`float` 数值类型和 `object` JSON 类型；对象 JSON 输入实时校验，格式错误阻止保存、校验前自动保存及部署。
- 创建新部署冻结前强制保存未保存草稿并执行最新平台校验；只有校验通过且校验期间没有新修改，才会请求创建冻结版本。已有 deploymentId 的预检重试直接读取冻结快照状态，不受之后草稿校验结果影响。
- 业务校验响应在进入状态或冻结门禁前核验问题字段、严重级别及错误/提醒计数和 `ok` 一致；编辑接口携带的校验投影复用同一解析器，格式异常会清除旧校验并显示读取错误。
- 细粒度编辑回执按后端成功/拒绝 DTO 区分解析，成功时核验 businessId、版本与校验投影；畸形成功回执会先重读业务定义恢复服务端权威状态，再提示回执错误。
- 冻结回执与本次请求的业务 ID、已校验版本及本机/对端设备 ID 一一核对；部署向导禁止将同一终端绑定到两个角色，冻结响应 DTO 按后端 nullable 字段建模。
- 冻结业务/版本/绑定回执核对已逐字段对照后端 `FreezeOutcome.Frozen`；后端将未使用对端及无初始环节的运行字段序列化为 `null` 时，前端按 nullable DTO 接受并保留原始响应。
- 调试主视图状态要求 image/canvas 模式与对应活动会话规格一致；图片接收计数不得超过预期字节数，只有精确收齐时才开放 complete。
- 运行详情兼容并显式标记后端 `business.trigger` 在首个业务步骤前拒绝的终态（停止索引 0、无步骤摘要）；普通停止步骤还要与 `stoppedAtAction` 对应。
- 业务编辑器校验定位覆盖顶层业务名称与用途说明字段；后端若将问题定位到 `name` 或 `description`，点击问题可聚焦对应输入框。
- 业务编辑器参考设备与部署绑定选项显示后端 `capabilitySyncState`（READY/握手/Schema 同步/终端确认/失败）；部署说明区分冻结校验编译、在线/租约预检与安装可能被终端拒绝。
- 业务编辑器有未保存草稿时，离开路由或切换业务会先确认放弃；保存进行中拒绝切换，刷新/关闭页面触发浏览器原生离开提示。

- 阶段 A：导航主入口为终端、业务、部署、调试；新增业务编辑、部署列表/详情、运行详情路由。移除旧节点工作流和独立模板页面、对应 API/类型，以及旧命令与 Section Patch 调试组件。前端静态调用扫描未发现 `/node-workflows`、`/ui-templates`、旧 `/events/catalog`、旧命令调试、`commands/stream` 或 Section Patch 路径。
- SDUI 路由移入 `asyncRoutes` 权限过滤链路，确保 `meta.roles` 对菜单和直接深链接都生效；允许角色为 admin、editor、guest、sdui_only。
- 路由守卫在角色加载后逐层复核匹配记录的 `meta.roles`；被过滤且无法匹配的直接 URL 明确跳转 404，已匹配但角色不符时跳转 401。
- HTTP API 返回 401 时清除本地登录态并带原 URL 跳转登录，返回 403 时进入现有 401 无权限页；登录页自身的 401 保留在登录表单显示错误，不触发重定向。
- SDUI 管理 API 统一使用 30 秒默认超时；终端调试 request 最长 120 秒、部署安装/卸载 120 秒、视图传输 60 秒。业务码拒绝封装为保留 `code/data/apiResponse` 的异常并交由页面错误区呈现，HTTP/网络错误保留全局反馈；401/403 继续走权限跳转。冻结拒绝展示稳定拒绝码与服务端逐条 details。
- SSE 与二进制帧使用直连 Axios 时也共用 401/403 权限跳转处理；SSE 事件解析兼容 LF、CRLF、CR 分隔、跨网络分块及流结束时的末尾事件。
- 调试台事件流与请求流在意外关闭或瞬时网络错误后按上限 30 秒的指数退避自动重连；有效事件恢复后重置退避，切换设备/手动重连/离开页面时取消重连，401/403 不循环重试。
- 自动重连等待期间在调试台顶部显示当前正在重连的流名称，连接建立后清除提示。
- 后端两条调试 SSE 流每 15 秒发送 SSE 注释心跳，维持空闲代理连接并检测不可写连接；注释不产生业务事件，前端解析器忽略注释行。
- 调试台视图状态刷新以服务端活动会话为准：会话关闭时清除本地帧状态；活动 Image/Canvas 会话恢复模式、分辨率、调色板位数、帧率和已收帧数，支持页面重载后继续传输。
- 登录管理 API 的租户以经验证 JWT 用户名为准，后端 `X-Space-Id` 仅是匿名请求兜底；前端不从本地缓存注入空间头。认领、删除、设备详情、遥测和连接日志错误提示保留服务端业务原因。前端路由角色目前允许 admin/editor/guest/sdui_only 访问 SDUI；后端当前 `/api/**` 为 permitAll 且 `/api/auth/info` 固定返回 guest，API 级授权需以真实后端身份策略完成，不能由前端路由代替。
- 清理未被路由或组件树引用的旧 `management.vue`、`TrendChart.vue`、`ConnectionOverview.vue`；运行时代码静态扫描未发现退役节点工作流、独立 UI 模板、旧事件/命令/Section Patch 路径。
- 阶段 F 复扫确认旧工作流/模板/命令/Section Patch API 路径无调用、SDUI 路由目标均存在；删除未被引用的旧设备动作/触发器目录 API 封装，目录由业务 API 的当前端点统一提供。
- Vite `/api` 代理目标可通过 `VITE_API_PROXY_TARGET` 配置，默认仍为本地 8080；新增[前端手工联调清单](FRONTEND_MANUAL_ACCEPTANCE.md)，覆盖浏览器业务/部署/运行/调试闭环及验收记录栏。
- 阶段 B：业务列表、版本读取、完整定义保存和有序环节编辑；支持设备/外部触发、步骤增删和排序、`@` 值引用、服务端校验定位与转换器插入。设备动作目录可按参考终端加载。
- 业务列表与版本读取检查响应结构，避免将格式异常误显示为空列表或空白定义；创建业务在提示期间即锁定重复提交，并要求响应确认已保存定义与版本后再进入编辑器。
- 设备详情把屏幕业务来源明确展示为后端归属记录，并说明它不保证屏幕此刻仍显示该业务；草稿编辑、冻结部署和设备当前配置分开展示，避免卸载后仍保留的来源记录造成误读。
- 业务列表摘要逐条校验后再展示；界面/环节列展示环节数量和前两个环节 key，更多环节可悬停查看，空业务明确显示尚未配置环节。
- 业务编辑读取与完整定义保存验证返回的业务 ID、正整数版本及定义结构；格式漂移显示明确错误并保留未保存草稿，不会把无效响应标成已保存。
- 业务资源抽屉逐项校验业务 ID、界面来源和可引用值；冻结、预检、安装响应在写入页面状态前核对部署 ID、计数和逐设备条目，格式漂移进入明确错误反馈。
- 完整定义保存携带编辑器加载的服务端版本号；后端通过事务级业务 ID 锁串行化首次创建，再锁定当前定义行比对版本，过期草稿以冲突响应拒绝覆盖，并提示刷新、合并后重试。新建业务以版本 0 创建首版；服务层回归测试覆盖 expectedVersion 透传和负版本拒绝。
- 业务版本弹窗通过 `GET /businesses/{businessId}/versions` 读取后端不可变快照目录，按真实保存版本展示并可读取定义；不再只展示当前版本或推测连续版本。
- 业务历史版本目录校验版本名、正整数版本号与重复编号，并按版本降序展示；版本详情核对 businessId、version 以及定义自身 ID/名称/UI/环节结构，拒绝串业务或错版本响应。
- 新增租户隔离的部署分页目录 `GET /deployments?page=&size=&businessId=`，按冻结时间倒序展示业务版本、绑定设备及逐设备结果；支持全局部署入口和业务列表内的指定业务历史入口。
- 部署分页目录校验响应页码、页大小、单页条数与发起请求一致；按业务过滤时逐条确认业务 ID，拒绝错页或跨业务响应。
- 部署目录更换业务过滤条件时立刻回到第一页并清除旧页数据；若记录数量变化导致请求页越界，则按服务端 totalElements 自动重读最后有效页。
- 部署目录刷新失败时保留最近一次成功读取的当前页记录并显示过期警告；切换业务过滤条件仍会清空旧业务数据，不会把旧租户/业务快照冒充为新查询结果。
- 部署目录切页读取失败时明确显示目标页未加载，并标出当前保留记录所属页；分页器保持在有数据的页码。
- 冻结响应中的一次性外部触发凭据提供显式复制操作；剪贴板失败时提示手动复制，凭据仍只保留在页面内存且不会由详情接口重新取回。
- 部署详情的外部集成模板校验业务/实例结构，并在展示与复制时清空实例 credential 字段；新增复制模板操作，避免将一次性密钥混入可重复导出的 JSON。
- 部署详情按需展示外部触发调用约定：credential 放 JSON 请求体、`Idempotency-Key` header 优先于 body 字段；展示后端提供的租户/异步查询 instructions，并提示接受响应的 runId 查询方式。
- 动作参数标签直接展示目录中的必填标记、单位与数值范围；枚举和 JSON 输入也提示必填，减少配置到服务端校验阶段才发现约束的往返。
- 数值动作参数改为受控更新；清空可选值会删除 `step.with` 键而非保存 `null`，整数类型和目录 min/max 在保存到草稿前校验，非法输入保留上次有效值。
- 所有动作目录参数都可切换为 `@` 值引用输入，包括数值、布尔、枚举和对象/数组；转换器产出可以接入任意类型参数，引用字段保留相同校验定位锚点。
- 动作 `object` / `array` 参数的 JSON 表单校验顶层类型；对象、数组字面量不得互换，并支持以 JSON 字符串形式引用 `@资源名`，防止编辑器序列化错误值或破坏对象/数组引用。
- UI 数组项和 UTF-8 文本长度只显示后端目录实际声明的 min/max；目录未声明数组上限时明确显示未声明，不把前端内部无界哨兵呈现为设备配额。新建数值字段默认值会夹在目录范围内。
- 更换步骤动作时，若原动作存在参数、产出或界面绑定会先确认；确认后清理旧动作专属字段，取消则保留原动作和配置，防止提交遗留参数。
- 动作切换确认跨异步弹窗校验业务路由代次、编辑修订号和步骤归属；确认期间切换业务或移除/修改该步骤时，迟到确认不会污染当前草稿。
- 每个环节头部增加统一屏幕选择和“新建界面”快捷操作：设备触发环节写入 `entry.ui`，首环节通过重排 `uis[]` 设置初始屏幕，外部触发环节按选择创建/更新首个 `ui.show` 步骤并让步骤 `target` 与 UI `owner` 同步；沿用当前屏幕时不持久化额外字段，新建成功后自动选为该环节屏幕，移除已有首个切屏步骤前会显示确认。
- 屏幕控件按当前映射字段带校验锚点：设备入口 `flows[n].entry.ui`、外部入口首个 `flows[n].steps[0].ui`、初始界面列表 `uis[0]`，使后端位置问题跳转到该控件。
- 参考终端动作/触发器目录请求按所选 deviceId、请求序号和业务路由代次过滤迟到响应；切换或清除设备选择后旧能力不会覆盖当前目录，读取失败时不会残留上一台设备数据。
- 参考终端动作目录和交互目录分别处理成功与失败；一个目录请求失败不会清空另一个已成功目录，动作请求失败时回退到平台静态动作目录并显示按目录区分的错误。
- 设备交互目录按后端 id/source/configurable/maxResponses 校验，选项展示可配置状态和最大响应数；切换触发类型会确认清除旧名称/输入值或交互点/界面绑定，并校验确认期间编辑代次和环节归属。
- 业务定义 DTO 按后端 codec 的持久化字段收紧：设备入口只含界面与交互点，外部入口才含方法名与输入值；UI/Flow/Step 的顶层字段不再允许隐式扩展，避免编辑端误以为未知字段会被保存。
- 校验问题路径按后端 `flows[n].steps[n].with.x`、`flows[flowKey].steps[n]`、`flows[n].entry.x`、`uis[n].fields.x` 格式映射到具体控件；点击后滚动并聚焦，未渲染的数组项回退到所属配置卡片。版本读取入口只显示列表 API 明确返回的当前版本，不再臆测历史版本连续。
- `ui.show` 展示必填字段缺失时，后端的 `flows[i].steps[j].ui.fields.x` 会按步骤引用的 UI key 映射到实际 `uis[n].fields.x` 编辑控件，避免只停在步骤卡片。
- 校验字段定位增加清晰的短时轮廓/背景高亮和固定顶栏滚动边距，让跳转位置可见。
- 对照后端所有 ConfigProblem location 补齐外部触发值类型、整机 scene 配额、设备槽位和镜像设置锚点；无字段级位置时可聚焦到所属配置控件或环节列表。
- 手动校验遇到未保存草稿时先保存，再请求服务端校验，避免校验旧版本；保存或校验失败显示在配置检查区域。
- 草稿发生本地修改时立即清除上次校验结果和转换建议，避免基于旧引用/旧类型继续插入 `ai.stt` / `ai.tts`。
- 业务保存提交不可变定义快照，并以编辑修订号判断响应是否仍对应当前草稿；保存期间发生的新编辑不会被旧响应覆盖。细粒度服务端编辑若等待保存期间又出现新改动，会中止本次编辑并提示先再次保存；校验结果也绑定对应修订，冻结部署会阻止提交期间新增的未保存草稿继续进入冻结流程。
- 业务编辑器标题实时显示“有未保存修改 / 已保存”，保存按钮仅在草稿有变更时可用；部署说明继续明确保存只改定义，不会更新设备。
- 删除 UI 前列出初始界面变更及仍引用它的触发器/步骤；若仍有步骤目标或 UI 归属指向对端，设备形态开关会阻止关闭并要求先重分配。
- 设备形态关闭被阻止时逐项列出仍指向对端的界面/步骤，点击即可定位到 owner/target 控件；清单随草稿重分配实时更新。
- 可转换的 `type_mismatch` 问题仅在后端返回 `converter` 且目标 `.with`/`.bind` 字段是明确的 `@引用` 时显示一键插入；通过编辑器转换端点写入步骤并重新读取定义与校验。
- 镜像区分编译镜像开关与“生成槽位互换配置”操作；后者只在双设备形态启用，确认影响后先保存草稿，再调用 `/editor/.../mirror`，由后端保存互换结果并返回校验版本。
- 环节与步骤提供有序上移/下移；部署启动环节固定，避免排序时改变初始触发语义；其余带触发器的环节可在组内排序。
