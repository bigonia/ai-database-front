# SDUI 前端手工联调清单

本清单记录浏览器前端与后端管理面、LCD085 平台模拟器的联调步骤。自动构建通过、M 系列 HTTP 对拍通过，都不能替代浏览器实际操作记录；模拟器结果也不能标记为 LCD085 真机通过。

## 环境准备

1. 准备一个可丢弃的 PostgreSQL + pgvector 数据库及专用应用账号。不要使用默认 `rag_db` 做验收写入。
2. 在 AgentNexus 仓库启动后端；把凭据填入当前 shell 环境，不要写入仓库文件：

   ```bash
   export DB_URL='jdbc:postgresql://127.0.0.1:5432/<专用验收库>?reWriteBatchedInserts=true'
   export DB_USERNAME='<验收应用账号>'
   export DB_PASSWORD='<验收应用密码>'
   ./mvnw spring-boot:run -Dspring-boot.run.profiles=macos \
     -Dspring-boot.run.arguments='--server.port=18080 --spring.ai.mcp.client.enabled=false' -DskipTests
   ```

   就绪检查：`curl -i http://127.0.0.1:18080/api/v1/sdui/catalog`，应返回 HTTP 200 和 `code: 20000`。
3. 在前端仓库启动开发服务器，让 Vite `/api` 代理指向同一后端：

   ```bash
   VITE_API_PROXY_TARGET=http://127.0.0.1:18080 npm run dev:test
   ```

   页面地址为 `http://localhost:8001`。Vite 代理默认目标仍是 `http://127.0.0.1:8080`，该环境变量用于隔离端口联调。
4. 在 AgentNexus 仓库启动终端模拟器。先用普通设备 ID 验收，可另加 `--trigger button.pwr.short_press --trigger-after 2` 让模拟器在首次规则替换后触发一次本地按键：

   ```bash
   python3 -u docs/sdui/terminal/lcd085_platform_simulator.py \
     ws://127.0.0.1:18080/ws/sdui/v2 --device-id LCD085-FRONT-SIM-001 \
     --trigger button.pwr.short_press --trigger-after 2
   ```

   终端输出应能看到 hello/schema/ready 协商。首次启动时从模拟器输出中取得认领码，在前端终端管理页完成认领。

## 自动化辅助命令

浏览器验收前后，可在 AgentNexus 仓库运行与目标范围匹配的已有对拍脚本。它们直接调用后端，不验证前端页面，所以结果单独记录：

```bash
python3 scripts/sdui-m10-acceptance.py --base http://127.0.0.1:18080
python3 scripts/sdui-m8-acceptance.py --base http://127.0.0.1:18080
python3 scripts/sdui-m9-acceptance.py --base http://127.0.0.1:18080
```

M8/M9 会连接或启动模拟器并写入验收业务/运行记录；仅对专用验收库和独立端口执行。脚本通过只证明其覆盖的后端路径，不证明前端 UI 操作成功。

## 调试台布局专项验收

- 桌面宽屏：左侧依次为设备控制、灯光控制、UI 展示、音频控制；中间列依次为 Canvas 画板、图片展示；最右侧为执行结果与最近操作。灯光参数与开关仅出现在灯光控制卡片。
- 左侧控制区宽度在 460–560px 之间（1600px 视口以下收窄到 380–440px），表单标签与输入控件不再互相挤压；中间列使用剩余空间，Canvas 与图片卡片同宽。
- 设备控制的参数输入与下发按钮同排：每个可调参数（音量、亮度等）压缩为一行「标签 + 数值框 + 按钮」，数值框不再显示加减按钮（直接输入，min/max 仍生效）；无参快捷指令（重启、配网）两列一行排列在「快捷指令」标题下；复合参数动作（如音频播放）整行展开、参数横排、按钮独占一行。
- 灯光控制的模式、颜色、亮度与「应用 / 关闭」按钮合并为一行，窄栏下允许按钮换行。
- UI 展示卡片的页面预览位于模板下拉右侧，标题、正文、动态字段与数组编辑器在左侧单列顺排，「下发到终端」为独立按钮；控制区宽度不超过 420px 时预览回落到模板下方。
- 音频控制的模式切换（文本转语音 / 音频文件 / 提示音）与对应的播放按钮（合成并播放 / 播放文件 / 提示音按钮）同排，播放文本与音频文件输入在其下方。
- 画板按正方形自适应填充 Canvas 卡片可用宽度，显示宽度不超过 520px；画布与画笔、终端发送参数跟随画板。卡片头部显示分辨率与帧率，设置区顶部用画布信息条汇总分辨率、调色板、单帧字节数与画笔大小，避免大面积留白。
- Canvas 卡片内部宽度超过 780px 时，画板与设置区左右排布；不超过 700px 时改为上下排布，设置区在画板下方横向展开。窄屏不保留固定画板高度，使用页面滚动。
- 左侧卡片等宽，表单紧凑排列；左侧与中间列分别滚动，互不影响。未选择终端时显示居中的空状态卡片与「刷新终端列表」按钮。
- 执行结果按内容确定高度，最多占记录栏的 45%；空状态下最近操作紧接执行结果。历史记录较多时在记录栏内滚动；展开请求数据不遮挡最近操作。
- 检查 1920×1080、1600×900、1366×768 和窄屏下的字段换行、模板预览、图片裁剪及 Canvas 绘制。窄屏自动改为纵向布局，所有按钮可访问。
- 验证音量、亮度、灯光、模板下发、图片上传、音频播放和画板撤销/发送仍可操作。
